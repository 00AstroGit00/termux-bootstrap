# Contributing to Termux Bootstrap Framework

Thank you for taking the time to contribute!

## Development Workflow
1. Fork the repository and create your branch from `main`.
2. Follow standard Bash / POSIX style rules (`set -euo pipefail`).
3. Ensure all scripts pass `shellcheck` static analysis.
4. Run the automated test suite before opening a pull request:
   ```bash
   bash tests/run_tests.sh
   ```
5. Submit your Pull Request with clear commit messages and documentation updates.
