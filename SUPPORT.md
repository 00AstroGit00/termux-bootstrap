# Support Guide

## Community & Technical Support

If you need help using the Termux Bootstrap Framework:

1. **Documentation**: Read the complete documentation suite in the [`docs/`](docs/) directory.
2. **Diagnostics**: Run `./doctor.sh` to diagnose network, package, or environment issues.
3. **Self-Healing Repair**: Run `./repair.sh` to automatically fix APT lock errors or permission issues.
4. **GitHub Discussions**: Open a Q&A thread in GitHub Discussions.
5. **Issue Tracker**: Report bugs via GitHub Issues using our standard Bug Report template.
